## Skenario

1. `eproc.agreement` (rate contract) + `eproc.agreement.line`.
2. `EprocOrder._validate_stock_agreement_pricing` (eproc_tc.py:5441).
3. Receiving Bay `action_confirm_srb` → `confirmed`; Receiving Validation `action_confirm_srv` → `_complete_receipt` → `done`.
4. `_create_accounting_impacts`: Dr persediaan / Cr stock input (+ opsional jurnal harian TC Stock Receipt).
5. Job aggregation (`_scheduler_baseprice_aggregation`) jika harga terima > base price aktif → `tariff.aggregation` pending → realize → draft base price ≥ H+2 → rollover.
6. `tariff.dependency` (penjamin ← BASEPRICE) × `tariff.markup` → `tariff.pricelist.fixed` (`_compute_dependency_fixed_price_vals`).
7. Export/TXT `^` (D01209) → NAS → TrakCare; `state_tc = sent`.
8. `trx_stock_move` → `eproc.stock.move` `DIS_*` (D016), plus `sale.order.line` item tagihan.
9. Jurnal TC Stock Dispense dari `view_account_tc_stock_movement`.
10. `trx_billing` → `sale.order.bill` (payer_amount / personal_amount), item di `sale.order.line`.
11. Saat `account.coveringletter.action_confirm`: Dr AR payer / Cr AR Unbilled.
12. `receivable.receipt` → `receivable.receipt.settlement` → `trx_receipt_collection` → TC.
13. `doctor.fee.line` dari item tagihan; rate dari `doctor.rate.line` (service × item × patient type × type_rate); posting via `doctor.fee.posting.wizard`.
